Dokumentasi API

Panduan Integrasi Universal

Semua request ke API v1 harus menyertakan header autentikasi berikut untuk validasi akses dan tracking kuota.

Header Nilai
X-API-Key API Key Anda yang aktif (Dihasilkan dari Dashboard)
Content-Type application/json

Error & Troubleshooting

401 Unauthorized: API Key salah, tidak aktif, atau tidak dikirim dalam header.
403 Forbidden: IP Address pengirim tidak terdaftar dalam Whitelist API Key tersebut.
429 Too Many Requests: Kuota (Prepaid Limit) sudah habis. Silakan top-up atau naikkan limit.

Endpoint Tersedia

GET /v1/cities

Mengambil daftar kota operasional lengkap dengan Provinsi, Kode Pos, dan Tipe (Kota/Kab).

Contoh Response: [{"id": 6, "name": "Surabaya", "postal_code": "60111", ...}]
GET /v1/couriers

Mengambil daftar kurir yang didukung (JNE, J&T, SiCepat, dll) beserta Logo & Deskripsi layanan.

GET /v1/cost

Cek tarif berdasar rute. Wajib mengirim query param: origin_id, destination_id, courier_code.

Mengembalikan JSON berisi estimasi harga dan waktu (ETD) untuk berbagai tipe layanan (REG, YES, OKE).
GET /v1/tracking/{awb}

Pantau status paket secara Real-time. Masukkan nomor Resi (AWB) pada path parameter. Mendukung fitur Cetak Label Pengiriman (PDF) melalui endpoint terpisah.
